# Pi Context Lifecycle

Extension-owned coordination for safe Pi context compaction, resume admission, and fresh-session handoff.

This repository is the lifecycle authority for the cross-extension contract tracked by [yourdigitaltoolbox/ydtb-control-plane#66](https://github.com/yourdigitaltoolbox/ydtb-control-plane/issues/66).

Implementation is developed on review branches. `main` begins as a minimal public source identity.
